INTRODUCTION

About the Project

This project uses Deep Learning to demonstrate how applicant information can be processed by an Artificial Neural Network (ANN) to predict a loan application outcome. It is developed for academic and educational purposes.

DATA

Dataset Overview

The model uses a secondary dataset obtained from Kaggle. It contains applicant information such as income, education, employment status, loan amount, credit score and asset values.


Dataset Source: Loan Approval Prediction Dataset by Archit Sharma.
